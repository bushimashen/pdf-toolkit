# PDF 工具箱 · PDF Toolkit

> 合并、拆分、删页、旋转、加文字水印、加页码——全部在浏览器里完成。不上传、无服务端、断网可用。

## 功能

| 页签 | 做什么 |
|---|---|
| **合并** | 多份 PDF 拼成一份，合并前可用 ↑ ↓ 调顺序 |
| **拆分** | 只保留你列出的页（`1-3,5,8-`），导出一份新 PDF |
| **删除页** | 去掉你列出的页，其余原样保留 |
| **旋转** | 90° / 180° / 270°，可作用于全部页或指定页 |
| **水印** | 文字水印：九宫格位置、字号、透明度、角度、颜色，另有「平铺满页」模式 |
| **页码** | 四种样式、五个位置、可设起始编号与字号 |

全部在本地跑。放进一份 PDF，拿回一份新 PDF，原文件不被动过。

## 为什么做这个

网上大多数「免费在线 PDF 工具」是把文件传到服务器、再给你一个下载链接。合同、证件扫描件、内部
汇报材料走这条路并不划算。`pdf-lib` 是一个纯 JavaScript 的 PDF 读写库，直接跑在页面里——文件
不出本机，而且关掉网络照样能用。

## 几个值得一提的细节

**中文水印要过一道 canvas。** `pdf-lib` 内置字体是 PDF 标准 14 款，全部不含 CJK 字形，
`drawText('内部资料')` 会直接抛错。所以水印文字先画到离屏 `<canvas>` 上（字号/颜色/角度/透明度
随你调），烘成一张透明 PNG，再作为图片贴到每页。附带的好处：浏览器里有的字体都能用，旋转和半透明
也顺手就有了。

画布尺寸取的是**旋转后的真实外框**（`w·|cos| + h·|sin|` 那一套），而不是对角线长度的正方形。
后者 70–90% 是空白像素，会让内嵌 PNG 无故胖一个数量级，视觉上却没有半点提升。

**页码故意用 Helvetica。** 页码只含数字和 ASCII 符号，PDF 标准字体足够覆盖，任何阅读器都不会出现
缺字方块。

**旋转是叠加的。** `page.setRotation()` 写的是 `/Rotate` 项，所以工具先读当前值再相加，而不是覆盖
——连转两次得到 180°，不是又回到 90°。

**页码表达式很宽容。** `1-3,5,8-` 解析为 `{1,2,3,5,8,9,10}`；超范围的数字自动裁掉；倒着写
（`3-1`）会交换首尾；留空 = 全部页。如果一次删光了所有页，会直接拦下报错，而不是产出一个 0 页文件。

## 使用方法

保持目录结构——`index.html` 按相对路径加载 `vendor/pdf-lib.min.js`。

```bash
python -m http.server 8000   # 然后打开 http://localhost:8000
```

直接双击 `index.html`（`file://`）通常也行；如果你的浏览器限制了本地脚本加载，页面会弹一条红色
提示说 `pdf-lib` 没加载成功，这时用本地服务器最稳。

## 兼容性

现代 Chrome / Edge / Firefox / Safari 均可。只用到 `Promise`、`Set`、`canvas.toBlob`、
`File.arrayBuffer` 和 `<input type="file">`，无构建步骤、无 polyfill。
